# Udemy Clone Website

A responsive Udemy-inspired e-learning website clone built using **HTML** and **CSS**.  
This project recreates the core structure and design of the Udemy platform, focusing on clean UI design, responsive layouts, and organized course presentation.

## Features

- Responsive navigation bar with logo, search bar, and menu links
- Udemy-style menu section for easy navigation
- Recommended Courses section with course cards, images, and details
- Recommended Topics section with topic suggestion input
- Popular Courses section displaying highly rated courses
- Fully responsive design using Flexbox and Grid
- Footer section with useful links and copyright information

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Purpose of the Project

The main objective of this project is to improve front-end web development skills by recreating a real-world learning platform interface. It focuses on responsive design, layout structuring, and modern UI styling techniques.

## How to Run

1. Download or clone the repository
2. Open the `index.html` file in any web browser
